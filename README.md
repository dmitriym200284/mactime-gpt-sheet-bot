# MacTime GPT Sheet Bot

🤖 Генератор контента из Google Sheets с помощью OpenAI API (GPT-4)

## 📦 Что делает

- Читает задачи из таблицы Google Sheets
- Отправляет запросы в GPT API
- Возвращает сгенерированный текст в таблицу

## 🛠️ Установка

```bash
pip install gspread oauth2client openai
```

## 🌐 Посадочная страница

Добавлен шаблон лендинга `landing.html` (русский язык) для презентации методологии «НейроВремя».

### Быстрый предпросмотр

- Для локального предпросмотра запустите сервер в корне проекта:

```bash
python3 preview_server.py
# при необходимости: PORT=8000 python3 preview_server.py
```

Сервер слушает `0.0.0.0` и подставляет `index.html` даже для неизвестных URL, поэтому вкладка Preview и проброшенный порт больше не показывают `Not Found`.

- Откройте `http://localhost:8000/` — лендинг открывается сразу как главная страница (`index.html`).
- Альтернативно можно открыть `http://localhost:8000/landing.html`.
