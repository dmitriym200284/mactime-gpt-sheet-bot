# Transcription Service Finder MVP

Веб-приложение для подбора сервисов транскрибации аудио и видео. Поддерживает фильтры по задачам, партнёрским программам, русскому языку, бесплатному тарифу, форматам экспорта, способу обработки и уровню уверенности данных.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Деплой на Vercel

1. Import Project в Vercel из этого репозитория.
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`
4. Output Directory: `dist`

## Ограничения MVP

- данные обновляются вручную;
- кнопка «Обновить данные» работает в демо-режиме;
- обратная связь сохраняется только в интерфейсе;
- клики считаются только в текущей сессии;
- для продакшена подключить Google Sheets / Supabase / аналитику.
